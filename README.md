# RuneCore

RuneCore optimizes real-time data processing through load-balancing and cache-optimization techniques within a scalable framework cluster architecture.

RuneCore is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/RuneCore.git`
2. `cd RuneCore`
3. Install in editable mode: `pip install -e .`

## Configuration

RuneCore is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
